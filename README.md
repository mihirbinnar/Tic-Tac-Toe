# 📖 Overview

Tic-Tac-Toe is a simple two-player strategy game where players take turns marking **X** and **O** on a 3×3 board. The first player to align three symbols horizontally, vertically, or diagonally wins the game.

This project recreates the classic game with an intuitive interface using **Streamlit**, making it playable directly in a web browser.

# 🎮 How to Play

1. Player **X** starts the game.
2. Click on an empty cell to place your symbol.
3. Players alternate turns.
4. The first player to make three symbols in a row wins.
5. If all cells are filled without a winner, the game ends in a draw.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/mihirbinnar/Tic-Tac-Toe.git
```

Move into the project

```bash
cd Tic-Tac-Toe
```

Install dependencies

```bash
pip install -r requirements.txt
```

---

# ▶ Run the Application

```bash
streamlit run app.py
```

The application will open automatically in your default browser.
